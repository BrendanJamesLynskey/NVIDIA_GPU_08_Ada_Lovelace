# Ada Lovelace — RTX 40, L40S, and Consumer-Class AI

A deep dive into NVIDIA's Ada Lovelace architecture: the AD102 die powering the RTX 4090, RTX 6000 Ada, L40S and L4; 3rd-generation RT cores with opacity and displaced micro-meshes; DLSS 3 with the Optical Flow Accelerator; 4th-gen tensor cores adding FP8 (no Transformer Engine on consumer); and the consequences of NVIDIA dropping NVLink from the consumer family. Includes an interactive Ada SKU picker.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_08_Ada_Lovelace/

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
